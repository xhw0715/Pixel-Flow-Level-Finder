What Is Sand Blocks: Drop Puzzle?
Pull colored sand into matching slots and clear the board grain by grain

Sand Blocks: Drop Puzzle is a free mobile physics puzzle. Pull each colored sand block toward the matching slot. The sand flows, piles, and collapses like a real falling-sand simulation until it fills every gap. The rule takes one sentence, but one wrong pull can trap two colors against each other.

Core gameplay: pull, flow, fill

The rules fit in three lines. Everything else is order planning.

1

Pull a matching color

Hold a color and drag it toward the correct slot. The entire stream of sand follows that route.

2

Watch the physics settle

The sand does not teleport away. It flows grain by grain, piles up, collapses, and slides around obstacles into the gaps.

3

Fill every slot

Clear the level when every slot is filled and no loose sand remains on the board.

Four steps for a smooth clear

1

Scan the board first

Before you touch anything, find every color and its largest slot. Ten seconds of looking can save most of a restart.

2

Fill the largest gap first

The color with the most sand takes longest to drain. Move it early to leave room for the streams that follow.

3

Pull in sequence

Let one stream settle completely before starting the next. If a color is blocked, clear the color in front of it first.

4

Finish the last grain

The level ends when every slot is full. If you get stuck, watch a solution and retry with a new order.

Features and game mechanics

Light, offline, and easy to pick up, but the hardest boards still demand careful planning.

🏖️ Real falling-sand physics

Sand flows, piles, and collapses instead of disappearing. You can read where each stream will go before letting go.

⏱️ Timed, but no move limit

There is no step budget. Time is the only pressure, so you can plan the pull order before making a move.

📶 Fully offline

Every installed board is self-contained. Play on a plane or subway without a connection.

📈 Four difficulty tiers

Beginner through Expert boards raise the color count and tighten the space. The guide covers 550 levels with video.

🆓 Free download, ad-supported

Free on Android, with ads supporting development. You can still finish every level without paying.

🧠 One minute to learn

The rule is simpler than a tutorial. Hard boards require planning several pulls ahead, which is where the hook lives.

Expert tips for a stuck board

Largest gap first

Fill the biggest sand gap before the small ones. It keeps the board open for the streams that still need space.

Wait on scattered sand

Do not pull a scattered color early. Open the board first, then drain all of its grains in one clean route.

Pull once, let it settle

A few seconds of planning can save minutes of repeated dragging. Check which colors will block each other before you start.

Restart when it jams

If four or five pulls leave no clear route, restart. A clean board is faster than untangling scattered sand.

Frequently asked questions

How do you play Sand Blocks: Drop Puzzle?

Pull colored sand toward the matching slot. The sand flows and settles under physics until it fills the gaps. Fill every slot before time runs out; there is no move limit.

Is Sand Blocks free?

Yes. The game is free on Android, supported by ads. You can finish every level without paying.

How many levels are there?

The game has hundreds of levels across Beginner, Intermediate, Advanced, and Expert tiers. The guide currently has 550 complete video walkthroughs and keeps adding new clears.

Where can I find a level answer?

Search the Sand Blocks Guide level library by level number. Each page has a YouTube solution with the exact pull order and a written recap.

Why do I keep getting stuck on the same level?

Most dead boards come from pulling a color too early and trapping another color in a corner. Fill the largest gap first, leave scattered colors for later, and clear the blocking color before opening a new route.

Does Sand Blocks work offline?

Yes. After installation, normal play works without an internet connection.
